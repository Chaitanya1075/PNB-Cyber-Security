# 🛡️ QuantumShield — PNB Cybersecurity Intelligence Platform

QuantumShield is a high-fidelity cybersecurity intelligence prototype designed for **Punjab National Bank (PNB)**. It provides a cinematic, "deep blue" command center interface for real-time monitoring of digital assets, risk assessment, and threat detection.

## 🔍 Key Features

### 📊 Executive Dashboard
* **Real-time KPI Tracking**: Monitor active assets, critical vulnerabilities, and network health at a glance.
* **Risk Heatmap**: Visual representation of risk distribution across the infrastructure.
* **Activity Feed**: Live logging of security events and system scans.

### 📋 Asset Inventory & Management
* **Deep Asset Visibility**: Detailed tracking of servers, databases, and endpoints.
* **Automated Scans**: Trigger manual or scheduled infrastructure scans.
* **Certificate Monitoring**: Timeline view of SSL/TLS certificate statuses and expiration alerts.

### 🗺️ Geospatial Intelligence
* **Global Threat Map**: Interactive visualization of login attempts and potential attack vectors by geographic location.
* **Visual Network Graph**: Dynamic representation of core infrastructure nodes and their connections.

## 🛠️ Technical Stack
* **Frontend**: HTML5, CSS3 (Modern Flexbox/Grid)
* **Visuals**: Canvas API for dynamic network visualizations
* **Typography**: Rubik, IBM Plex Sans, and Chakra Petch for a high-tech "Command Center" feel
* **Design System**: Custom glassmorphism-based UI with a "Quantum Deep Blue" cinematic palette

## 🎨 Design Philosophy
The prototype uses a **Deep Blue Cinematic** design system, focusing on high contrast, readability, and data-density. Key UI elements include:
* **Glassmorphism**: Translucent surfaces with blur effects for a modern look.
* **High-Impact Badges**: Color-coded risk levels (Critical, High, Medium, Low) for instant situational awareness.
* **Animated UI**: Smooth transitions and pulse animations to simulate a live, "breathing" system.
